# FitSphere — Fitness Center Management Website

A responsive front-end demo based on the supplied project brief.

## Features
- Dashboard with member, trainer, class and attendance summary cards
- Member list with search and an interactive Add Member dialog
- Trainer, class schedule, workout program and attendance sections
- Weekly attendance chart with period selector
- Responsive sidebar for mobile screens

## Run
Open `index.html` in a browser. No build tools are required.

This is a front-end demo. Data is held in browser memory and resets when the page is refreshed. Connect a backend/database for persistent records and real authentication.
